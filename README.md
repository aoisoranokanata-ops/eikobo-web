# 映工房 Web

iPad で使う動画編集アプリ（ブラウザで動く PWA）。映工房（Windows 版）の姉妹アプリです。

公開先: https://aoisoranokanata-ops.github.io/eikobo-web/

## 使い方
1. Safari で開き、共有ボタン →「ホーム画面に追加」（全画面で使え、端末の保存領域も消されにくくなります）。
2. 「＋ 新しい作品」→「＋ 読み込む」で、写真アプリ・ファイル・iCloud Drive から動画・音声・画像を選びます。
   タイムラインが空なら、読み込んだ順に並びます。素材の「＋」で再生位置に置けます。
3. タイムライン
   - 指でクリップをタップして選ぶ → もう一度ドラッグで移動（上下の段にも）。端の黄色い取っ手でトリム。
   - 選んでいない所のドラッグは画面の移動、2 本指で拡大縮小。Apple Pencil・マウスはどのクリップもそのまま動かせます。
   - 目盛りを触ると再生位置が動きます。
   - 「分割」は再生位置で切ります（選んでいればそのクリップ、無ければ全部）。「詰めて削除」は空いた所を詰めます。
   - 見出しの「目」= 映像の表示、「M」= ミュート、「S」= ソロ、「鍵」= ロック。トラック名を触ると名前・音量・削除。
4. プレビューで選んだクリップをドラッグ = 移動、角 = 拡大、2 本指 = 拡大と回転。細かい値は右の「調整」で。
5. 保存は自動です（左上に「保存済み」）。
6. テロップ: 「＋ テキスト」（キーボードは T）で再生位置に置き、右の「調整」で文字を打ちます。
   「カタログから選ぶ…」で 100 種のスタイル（★でお気に入り）、モーションで登場・強調・退場の動き（1 文字ずつも）。
   プレビューでドラッグ = 移動、2 本指 = 拡大と回転。
7. 字幕: 「字幕」から、再生位置に足す・SRT を読み込む／書き出す・字幕全体の見た目。字幕クリップの「話者」に名前を入れると
   吹き出しになります（1 人目は上・2 人目は下）。
8. 色: 映像・画像のクリップの「色」で、ルック（白黒・シネマなど）や露光量・コントラスト・彩度・色温度、LUT（.cube を読み込めます）。
   「切り抜き」で上下左右を削れます。「＋ カラー」で単色の背景（カラーマット）。
9. つなぎ: クリップの「前のクリップとのつなぎ」でディゾルブ・黒を挟む・ワイプ・スライド・ズーム（音はクロスフェード）。
10. キーフレーム: 位置・拡大・回転・不透明度・音量の左の ◆ で再生位置にキー。2 つ以上打つと間がなめらかに変わります。
   「前のキー／次のキー」で移動、「次への動き」で動き方（ゆっくり始まる など）。
11. 音: 「ミキサー」でトラックごとの音量・パン・ミュート・ソロ（メーター付き）、マスター音量とリミッター、
   「BGM の自動ダッキング」（声が入っている間だけ音楽を下げる）、「全体のラウドネス」（測って目標に合わせる）。
   音声クリップの「調整」で EQ・コンプレッサー・ノイズ除去、「音量をそろえる」（-14 / -16 / -23 LUFS）。
   「● 録音」で再生しながらナレーションを録り、録り始めた位置に置きます（イヤホン推奨）。
12. Windows 版とのやり取り: 作品一覧の作品の「⋯」→「Windows 版へ・バックアップ（.zip）」で、作品（.ekp）と素材・LUT を
   1 つの .zip に。Windows で展開して .ekp を映工房（Windows 版 1.3.1 以降）で開きます。逆は Windows 版で保存した .ekp
   （素材も入れるならフォルダごと .zip に）を作品一覧の「読み込む」で。見つからない素材は「素材」の「まとめて選ぶ」で名前で結びます。
   この .zip は Web 版どうしのバックアップ・別の端末への引っ越しにも使えます。
13. 右上の「書き出し」で MP4 にします（字幕を焼き込むか選べます）。範囲（全体・選んだクリップ）・大きさ・画質を選び、終わったら
   「共有・写真に保存」で写真アプリへ（共有シートの「ビデオを保存」）。書き出し中は画面を開いたままにしてください。

14. Google Drive: 作品一覧の「☁️ Google Drive」→ Google Cloud で作った「OAuth クライアント ID」を貼ります（作り方は画面に出ます。
   紙工房 Web と同じ ID を使えます。その時は「承認済みのリダイレクト URI」に映工房 Web の oauth.html を足してください）。
   - 作品のバックアップ: 作品の「⋯」→「☁️ Google Drive にバックアップ」、または「☁️ Google Drive」→「すべての作品をバックアップ」。
     マイドライブの「映工房 Web」フォルダに .zip（Windows 版へ・バックアップと同じ形）で入ります。戻すのは「バックアップから戻す」。
   - ドライブの .ekp / .zip を作品として:「☁️ Google Drive」→「作品を読み込む」。
   - 素材: 編集画面の「素材」の「☁️ Drive」で動画・音声・画像を。見つからない素材は「☁️ Google Drive から選ぶ」で名前で結びます。
   - 書き出した動画: 書き出しの後の「☁️ Google Drive に保存」。大きな動画は 32MB ずつ送り、途中で切れても続きから送ります。

### キーボード（Magic Keyboard など）
スペース 再生・停止／← → 1 コマ（Shift で 1 秒）／↑ ↓ 前後の編集点／S または ⌘K 分割／Delete 削除（Shift で詰めて削除）／
M マーカー／T テキスト／⌘Z 取り消し・⇧⌘Z やり直し／＋ − 拡大縮小／\ 全体

## 注意
- 素材はこの端末のブラウザの中に保存されます（他の端末とは共有されません）。
- 写真アプリから選ぶと、iPad が動画を変換して小さくすることがあります。元のままにしたい時は「ファイル」から選んでください。
- 書き出しは H.264＋AAC の MP4 です。音声を AAC にできない端末では、音声が無圧縮の MOV になります。

## 開発メモ
設計・確かめ方は CLAUDE.md。試験用の素材の作り方（ffmpeg）:
```
ffmpeg -f lavfi -i testsrc=size=1920x1080:rate=30:duration=8 -f lavfi -i sine=frequency=440:sample_rate=48000:duration=8 -c:v libx264 -pix_fmt yuv420p -c:a aac -ac 2 tools/fixtures/clipA.mp4
ffmpeg -f lavfi -i testsrc2=size=1280x720:rate=24:duration=5 -f lavfi -i sine=frequency=660:duration=5 -c:v libx264 -pix_fmt yuv420p -c:a pcm_s24le tools/fixtures/pcm.mov
```
